# PP-YOLOE+ Small: ресурсы и пригодность для Raspberry Pi 3

Дата измерения UTC: 2026-09-15T19:05:00.701005+00:00

## Вывод

Текущая реализация LightStore с Paddle 3.3.1 и Python/PyTorch-трекером не подходит
для переноса на Raspberry Pi 3 без переработки. На Mac она занимает примерно
1,45 ГиБ RSS под нагрузкой, тогда как Pi 3 B/B+ имеет 1 ГБ RAM на всю систему.
Это инженерная оценка по измерениям Mac, а не результат запуска на Raspberry Pi.
Сами веса невелики; основной расход связан с движком, библиотеками и промежуточными тензорами.

## Условия

- Apple M3 Pro, 12 логических CPU, 36 ГиБ RAM.
- PP-YOLOE+ Small Objects365, CPU, 640×640; входной кадр 640×480 JPEG.
- Исходная голова 365 классов; 78 классов пропускаются в трекер.
- Отдельный временный сервер на localhost:8002, та же конфигурация и код, что у живого приложения.
- Два повторяемых изображения; 5 прогревочных кадров, затем 241 кадров за 30.11 с.
- RSS процессов опрашивался каждые 50 мс; измерение включает запуск и загрузку весов.
- Сервер на localhost:8001 и его камера/счётчики не использовались в тесте.

минимальной сборки для Raspberry Pi.

## Почему Pi 3 не подходит для текущей сборки

1. **RAM.** У Pi 3 B/B+ 1 ГБ на ОС и приложение. Даже один Paddle-процесс на Mac
   превысил 1 ГиБ RSS. Полная система достигла 1,45 ГиБ до учёта камеры, браузера и ОС.
   Своп на microSD не следует считать решением для устойчивого видеопотока.
2. **CPU.** Pi 3 B использует четырёхъядерный процессор 1,2 ГГц, B+ — Cortex-A53
   1,4 ГГц. Из 8 FPS на M3 Pro нельзя достоверно вычислить FPS Pi. На самой плате
   замеров нет; обещать пригодную для быстрых переносов скорость оснований нет.
3. **Установка.** У проверенной версии `paddlepaddle==3.3.1` на PyPI есть Linux
   x86_64, macOS ARM64 и Windows x86_64 wheels; Linux ARM wheels отсутствуют.
   Нельзя просто перенести нынешнее окружение Mac или повторить тот же pip install
   на Pi. Понадобится другой совместимый runtime или отдельная сборка.
4. **78 классов — фильтр.** Сеть по-прежнему считает исходные 365 классов.
   Уменьшение разрешённого списка само по себе не уменьшает основную модель.

Оптимизированный вариант этой же сети может расходовать иначе. Его пригодность
не исключена математически, но требует отдельного экспорта, сокращения runtime,
проверки квантования и бенчмарка на Pi. Практический путь для фиксированного Pi 3 —
существенно более лёгкий детектор с небольшим набором товаров и оптимизированный
ARM runtime; целевая точность и FPS должны быть проверены на плате.

## Ограничения измерения

- RSS — резидентная память процесса. Сумма может повторно учитывать общие страницы;
  USS получить не удалось из-за ограничений macOS. Это не точный уникальный физический footprint.
- Не включены память браузера, ОС, захвата камеры и процесса, который проводил замер.
- macOS и Linux могут иметь разный расход памяти. Пик с шагом 50 мс может пропустить
  очень короткие всплески.
- Задержка включает сервер, IPC с Paddle, трекер, JPEG и localhost WebSocket.
  Она не включает захват камеры и отрисовку браузера. Сетевой объём — полезные
  данные сообщений, без TCP/WebSocket/HTTP overhead.
- Это тест производительности, не тест качества распознавания продуктов.
